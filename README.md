# Develop-a-Student-Record-Sorting-System-Using-Quick-Sort-and-Merge-Sort

Project Overview
The Student Record Sorting System is a Python-based project that demonstrates and compares two popular sorting algorithms: Quick Sort and Merge Sort.
The system sorts student records based on selected fields, such as student ID, name, age, marks, and GPA. It supports both ascending and descending order.
The main objective of this project is to understand how different sorting algorithms work and compare their performance using execution time.

Objectives
To implement Quick Sort and Merge Sort using Python.
To sort student records based on different fields.
To support ascending and descending sorting.
To compare the execution time of both algorithms.
To analyze their time and space complexity.
To understand which algorithm performs better under different test conditions.
